# ONG Patas & Laços 🐾

## Sobre o projeto

O projeto ONG Patas & Laços foi desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Front-End para Web.

O site apresenta uma ONG voltada à proteção e ao bem-estar dos animais, mostrando seus projetos e permitindo que pessoas interessadas realizem um cadastro para participar das ações.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Páginas

- **Início:** apresentação da ONG e informações de contato.
- **Projetos:** apresentação das principais iniciativas da ONG.
- **Cadastro:** formulário para pessoas interessadas em participar das ações.

## Funcionalidades

- Navegação entre as páginas.
- Máscara para CPF, telefone e CEP.
- Validação dos campos do formulário.
- Validação de e-mail.
- Mensagem de confirmação após o cadastro.
- Layout personalizado com CSS.

## Créditos das imagens

As imagens utilizadas no projeto foram geradas com auxílio de ferramentas de inteligência artificial (IA). Elas foram utilizadas para fins acadêmicos e demonstrativos, compondo o conteúdo visual do site fictício da ONG Patas & Laços.
